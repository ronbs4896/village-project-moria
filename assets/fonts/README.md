# ברזיה (Birzia)

פונט עברי-אנגלי מאת **עומר צופי**, בחמישה משקלים: Light, Regular, Medium, Bold, Black.

## איך מכניסים אותו

1. מורידים מאתר המעצב: <https://omerzofy.com/birzia-font/>
2. משליכים את הקבצים לתיקייה הזאת. **אין צורך לשנות שמות** — הבנייה מזהה כל קובץ
   לפי מילת המשקל בשמו (`light` / `regular` / `medium` / `bold` / `black`),
   בכל אחת מהסיומות `.woff2` `.woff` `.ttf` `.otf`.
3. `python3 build.py --render`

הבנייה ממירה `ttf`/`otf` ל-`woff2` (דרך fontTools), מטמיעה את הקבצים כ-base64
ומייצרת מחדש את ה-HTML, ה-PDF וה-PNG.

אם התיקייה ריקה, בלוק ה-`@font-face` מוסר אוטומטית והעיצוב נופל חזרה ל-Rubik
ו-Assistant בלי לשבור כלום.

## רישיון

הפונט מופץ לשימוש מסחרי בתנאי הרישיון של המעצב (2 מושבי דסקטופ ודומיין אחד לרשת).
**מורידים אותו מהאתר של עומר צופי בלבד** — לא מאתרי אגרגציה שמפיצים פונטים
בלי רישיון. הקבצים עצמם אינם נכללים ב-git.
