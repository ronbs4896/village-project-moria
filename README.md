# תפריט ראש השנה — מסעדת אלגריה

פוסטר מכירה לראש השנה של מסעדת אלגריה (רחוב הזית 118, קרית גת).
49 המנות מהתפריט המקורי, בתוספת באנר "המכירה הגדולה" עם תאריכים ושעות,
ורצועת שמונת סימני ראש השנה. גיליון A3 לאורך, נדפס גם על A4.

## תאריכי המכירה

התאריכים יושבים במקום אחד ב-`src/menu.html`, מתחת להערה
`<!-- ══ תאריכי המכירה — לעדכון כאן בלבד ══ -->`. אחרי שינוי מריצים
`python3 build.py --render`.

## מבנה

| קובץ | תפקיד |
|---|---|
| `src/menu.html` | מקור העיצוב — הקובץ היחיד שעורכים |
| `build.py` | בונה את התוצרים ומרנדר PDF/PNG |
| `index.html` | עמוד עצמאי לצפייה ולשיתוף (נבנה אוטומטית) |
| `dist/artifact.html` | פרגמנט עם לוגו מוטמע לפרסום |
| `dist/*.pdf` | A3 מוכן להדפסה (ובנוסף גרסת A4) |
| `dist/*.png` | תמונה לוואטסאפ ולרשתות |
| `src/simanim.py` | שמונת סימני ראש השנה כאייקוני SVG |
| `assets/` | הלוגו שחולץ ממדריך המותג + הגיידליינז המקוריים |

## בנייה

```bash
pip install playwright pillow pymupdf
python3 build.py --render
```

בלי `--render` נבנים רק קבצי ה-HTML.

## מערכת העיצוב

הכל נגזר ממדריך המותג הרשמי (`assets/brand-guidelines.pdf`) — אין צבע אחד מחוץ לפלטה.

| טוקן | ערך | שימוש |
|---|---|---|
| `--ink` | `#333333` | טקסט, באנרים, טאבים |
| `--cream` | `#F2EADE` | רקע הגיליון |
| `--orange` | `#F5871F` | סמני פריטים, פסי מותג |
| `--gold` | `#FCC50D` | כותרת משנה, מספר הטלפון |
| `--paper` | `#FCF8F2` | רקע הפאנלים (קרם מוגבה) |
| `--ink-soft` | `#6E6357` | טקסט משני |
| `--rule` | `#D9CBB6` | קווי שיער |

**מוטיבים** — שלושתם נגזרים מהמותג או מהמטבח, לא מבנק תמונות:

1. **הפלאק המקומר** של הלוגו הפך לצורת הטאב של כל קטגוריה, כולל קו הזהב הפנימי.
2. **פס הגרדיאנט** זהב→כתום מתחתית דפי הגיידליינז משמש כקו חוצץ מעל התוכן ומתחתיו.
3. **זליג' מרוקאי** — ריצוף כוכב שמונה־קצוות (ח'אתם) ומעוינים, שנבנה גאומטרית
   ב-`build`-time ולא צויר ביד. מופיע בארבע עוצמות: זהב על הפחם בכותרת ובתחתית,
   פחם על הזהב בבאנר המכירה, וסימן מים על גיליון הקרם. הבחירה נובעת מהתפריט עצמו —
   מטבוחה, זעלוק, מפרום, טנזייה, קובה וקוסקוס הם מטבח מרוקאי, ולא מ"עיצוב ראש השנה"
   הגנרי של רימונים וכדי דבש שכל מתחרה משתמש בו.

**רשת** — רשת-אם של שלושה טורים לאורך כל העמוד: בשרים ברוחב מלא (3×6), תוספות (2 טורים) ליד דגים
(טור אחד) בגובה זהה, וסלטים ברוחב מלא.

**טיפוגרפיה** — הפונט המבוקש הוא **ברזיה** של עומר צופי. הוא לא נשמר בגיט (רישיון),
אבל הפרויקט מוכן לקלוט אותו: מורידים מ-<https://omerzofy.com/birzia-font/>, משליכים את
הקבצים ל-`assets/fonts/` ומריצים `python3 build.py --render`. הבנייה מזהה את המשקלים לפי
שם הקובץ, ממירה ל-`woff2` ומטמיעה אותם כ-base64. בלי הקבצים העיצוב נופל חזרה ל-`Rubik`
ו-`Assistant` ונבנה כרגיל. פרטים ב-`assets/fonts/README.md`.

הפונט הראשי במדריך המותג, `Fb IguanaNew`, מסחרי ואינו זמין לאינטרנט. הוא נשאר שני
במחסנית — אם יש רישיון, הוא ייתפס אוטומטית מהמערכת בהדפסה.

## התאמה למסך

יחידת מידה אחת (`--s`) שולטת בכל הגדלים: 1 מ"מ בהדפסה, ומידה גדולה יותר במובייל, כך שאותו
קובץ נותן A4 מדויק בהדפסה ותפריט קריא בטלפון בלי לפרוש עיצוב שני.
