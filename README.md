# תפריט ראש השנה — מסעדת אלגריה

עיצוב מחדש של תפריט ראש השנה של מסעדת אלגריה (רחוב הזית 118, קרית גת).
**התוכן זהה למקור** — 49 מנות בארבע קטגוריות. מה שהשתנה הוא העיצוב, הפריסה והמבנה.

## מבנה

| קובץ | תפקיד |
|---|---|
| `src/menu.html` | מקור העיצוב — הקובץ היחיד שעורכים |
| `build.py` | בונה את התוצרים ומרנדר PDF/PNG |
| `index.html` | עמוד עצמאי לצפייה ולשיתוף (נבנה אוטומטית) |
| `dist/artifact.html` | פרגמנט עם לוגו מוטמע לפרסום |
| `dist/*.pdf` | A4 מוכן להדפסה |
| `dist/*.png` | תמונה לוואטסאפ ולרשתות |
| `assets/` | הלוגו שחולץ ממדריך המותג + הגיידליינז המקוריים |

## בנייה

```bash
pip install playwright pillow pymupdf
python3 build.py --render
```

בלי `--render` נבנים רק קבצי ה-HTML.

## מערכת העיצוב

הכל נגזר ממדריך המותג הרשמי (`assets/brand-guidelines.pdf`) — אין צבע אחד מחוץ לפלטה.

| טוקן | ערך | שימוש |
|---|---|---|
| `--ink` | `#333333` | טקסט, באנרים, טאבים |
| `--cream` | `#F2EADE` | רקע הגיליון |
| `--orange` | `#F5871F` | סמני פריטים, פסי מותג |
| `--gold` | `#FCC50D` | כותרת משנה, מספר הטלפון |
| `--paper` | `#FCF8F2` | רקע הפאנלים (קרם מוגבה) |
| `--ink-soft` | `#6E6357` | טקסט משני |
| `--rule` | `#D9CBB6` | קווי שיער |

**מוטיבים** — שניהם נלקחו מהמותג עצמו, לא הומצאו:

1. **הפלאק המקומר** של הלוגו הפך לצורת הטאב של כל קטגוריה, כולל קו הזהב הפנימי.
2. **פס הגרדיאנט** זהב→כתום מתחתית דפי הגיידליינז משמש כקו חוצץ מעל התוכן ומתחתיו.

**רשת** — רשת-אם של שלושה טורים לאורך כל העמוד: בשרים ברוחב מלא (3×6), תוספות (2 טורים) ליד דגים
(טור אחד) בגובה זהה, וסלטים ברוחב מלא.

**טיפוגרפיה** — הפונט הראשי במותג הוא `Fb IguanaNew`, שאינו זמין לאינטרנט. במקומו `Rubik`
לכותרות ו-`Assistant` לגוף. להחלפה לפונט המקורי בהדפסה יש לשנות שני משתנים ב-`src/menu.html`:

```css
--font-display: 'Fb IguanaNew', 'Rubik', sans-serif;
--font-body:    'Fb IguanaNew', 'Assistant', sans-serif;
```

## התאמה למסך

יחידת מידה אחת (`--s`) שולטת בכל הגדלים: 1 מ"מ בהדפסה, ומידה גדולה יותר במובייל, כך שאותו
קובץ נותן A4 מדויק בהדפסה ותפריט קריא בטלפון בלי לפרוש עיצוב שני.
